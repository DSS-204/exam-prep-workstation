# 🌸 酱酱备考工作台

> 安徽省考 / 事业编备考一站式移动端工作台 — 纯前端 PWA，数据本地存储，开箱即用

一个专为安徽省公务员考试（省考 + 事业编）设计的竖屏单列流式备考工具。无需注册、无需后端，所有数据自动保存在浏览器本地（localStorage），支持添加到手机桌面像 App 一样使用。

## ✨ 功能模块

### 🏠 首页工作台
- **公考倒计时** — 自动计算距离 2027 安徽省考笔试剩余天数
- **今日学习任务** — 行测 / 申论 / 时政三科任务管理 + 五星自评
- **备考倒数纪念日** — 记录备考天数里程碑
- **每日反思** — 今日不足 + 明日改进计划
- **运动规划** — 8 种运动类型，运动时长上限 90 分钟
- **待办清单** — 备考相关待办事项
- **作息记录** — 双向时间计算（改起止→自动算时长 / 改时长→自动算结束）
- **树洞心情** — 情绪记录与疏导
- **数据统计看板** — 学习时长可视化

### 📰 时政资讯专区
- 6 大分类时政新闻列表
- 月度归档 + 一键导出
- 重要会议专题（金句标红）
- 时政自测题 + 背诵抽查

### 💎 申论积累宝库
- **规范词宝库** — 8 大领域白话→规范表述卡片，三级掌握度
- **热点词汇** — 申论高频主题词
- **人民日报金句** — 仿写练习
- 易混概念对比

### 🎯 行测专项训练场
- **资料分析** — 速算技巧训练
- **加强削弱** — 逻辑判断题
- **图形推理** — 规律识别
- **成语辨析** — 高频成语
- 自动评分 + 错题自动同步到错题本

### 📢 招考信息雷达
- **公告汇总池** — 覆盖安徽 16 地级市，多维度筛选（类型/地市/状态/排序）
- **考试时间轴** — 8 节点全流程追踪（公告→报名→缴费→准考证→笔试→成绩→复审→面试）
- **报考工具箱**：
  - 专业目录查询（含**环境设计**归类：本科及以上 ＞ 设计学类）
  - 进面分数线检索（16 市 × 省直/市级/县级/乡镇）
  - 报名照片规范
  - 报考条件速查

### 📖 错题 & 收藏夹
- 行测错题自动归集
- 申论素材 / 时政金句收藏
- 统一数据中心管理

## 🚀 使用方式

### 在线访问
手机浏览器打开部署链接，点击浏览器菜单「添加到主屏幕」即可像 App 一样使用。

### 本地运行
```bash
# 克隆仓库
git clone https://github.com/DSS-204/exam-prep-workstation.git
cd exam-prep-workstation

# 任意静态服务器启动
python3 -m http.server 8765
# 然后浏览器打开 http://localhost:8765
```

### PWA 安装
1. 用手机浏览器（Safari / Chrome）打开页面
2. 点击浏览器菜单 →「添加到主屏幕」/「安装应用」
3. 桌面出现独立图标，点击即可全屏使用

## 🛠️ 技术栈

| 技术 | 说明 |
|------|------|
| HTML5 + CSS3 + 原生 JS | 无框架依赖，单页应用 |
| localStorage | 数据持久化，`jj_` 前缀命名空间 |
| PWA | manifest.json + Service Worker 离线缓存 |
| 移动优先 | 390px 基准竖屏单列流式布局 |

## 🎨 设计特色

- **豆沙粉主题**：`#FBF6F2` 奶油底色 + 豆沙粉点缀，柔和不刺眼
- **圆角卡片**：全局 `border-radius: 16px`，亲和力强
- **情感化交互**：标语轮播、心情树洞、五星自评
- **跨模块联动**：做题错题→错题本、收藏素材→收藏夹、设定目标考试→首页倒计时同步

## 📝 考试时间说明

所有考试时间按 **2027 年安徽省考周期**对齐：

| 节点 | 预计时间 | 依据 |
|------|----------|------|
| 省考笔试 | 2027-03-13（周六） | 历年规律：3 月中旬周六 |
| 省考公告 | 2027-01 中旬 | 笔试前约 2 个月 |
| 成绩查询 | 2027-04 下旬 | 笔试后约 6 周 |
| 面试 | 2027-06 ~ 07 | 成绩后约 6-8 周 |

> ⚠️ 以上时间为根据历年规律推算的预计值，实际以官方公告为准。
